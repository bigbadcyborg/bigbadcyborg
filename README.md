## Featured Projects

### [Local LLM Reverse Engineering Toolkit](https://github.com/bigbadcyborg/AI-reverse-engineering)

A local-first reverse engineering assistant that analyzes decompiled code without sending sensitive data to third-party APIs.

**Highlights**

* Imports Ghidra-exported function data as JSONL
* Uses local LLM backends such as Ollama, llama.cpp, or LM Studio
* Generates function summaries, behavior hypotheses, and rename suggestions
* Includes a Flask dashboard, CLI workflow, SQLite search database, and Ghidra helper scripts
* Designed for lawful reverse engineering, CTFs, malware analysis labs, and defensive research

**Tech:** Python, Flask, SQLite FTS5, Ghidra scripting, local LLMs, JSONL, CLI tooling

---

### [PassiveGuard](https://github.com/bigbadcyborg/PassiveGuard-Fullstack)

A passive vulnerability scanning platform designed to analyze existing artifacts without intrusive probing or unnecessary network noise.

**Highlights**

* Static code analysis and taint tracking
* Dependency scanning with vulnerability database lookups
* Configuration analysis and network traffic log or PCAP inspection
* React dashboard with authentication and scan result views
* Flask backend, Celery background jobs, Redis queueing, Docker support
* Edge agent concept for privacy-preserving local scanning

**Tech:** Python, Flask, React, Celery, Redis, SQLite, Docker, JWT, static analysis

* Backward chaining inference engine
* Forward chaining decision tree traversal

### [3D Engine From Scratch](https://github.com/bigbadcyborg/3d-engine-from-scratch)
